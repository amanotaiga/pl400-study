# PL-400 Study Materials

Learning materials generated from **6 mock-exam sets (441 questions)**. Two layers:

1. **Concept Guides** — synthesized notes per exam domain: key facts, "when to use X vs Y" decision rules, comparison tables, and common traps. **Start here to learn.**
2. **Study Decks** — every question with its options, the correct answer marked ✅, and a de-duplicated rationale. **Use these to drill / self-test.**

Domains are ordered by exam weight (study the heaviest first).

## How it was built (token-efficient pipeline)

- [build_materials.py](build_materials.py) deterministically parses all 6 raw files into structured questions and emits the **study decks** + `_parsed/*.jsonl` intermediates — **zero model tokens** for content.
- 6 parallel subagents each read one `_parsed/*.jsonl` file and synthesized one **concept guide**, so the raw 1.3 MB never entered the orchestrator's context.

To regenerate decks after editing the raw files: `python build_materials.py`
(Concept guides are LLM-synthesized and are not regenerated by the script.)
